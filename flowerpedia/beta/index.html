Novedades de v0.2.2

  • Header móvil compacto con iconos y filtros agrupados.
  • Selector de productos por fila en lugar de estadísticas.
  • Composición compacta: precios y totales solo para administradores locales.
  • Información comercial más compacta con scroll interno cuando es necesario.
  • Usuarios: aparece la cuenta administradora actual.
  • Cajas: U2 individual con previsualización del peso y semáforo.
  • Sin medidas en pulgadas ni botón manual para preparar el catálogo público.
  • Compra UK colocada junto a Caja UK / OP UK en el formulario.
  • Inicio más estable: el navegador abre cuando el servidor responde.
  • Publicación de imágenes sin borrar la carpeta completa.
  • Excel activo: private/data/current_week.xlsx; sincronización automática cada 2,5 segundos.
  • GitHub Desktop publica los cambios de docs/; no se conecta a Drive.
Para administrar, ejecuta start.bat en Windows. GitHub Pages debe publicar desde /docs. La carpeta private/ y el BAT están excluidos del repositorio público por .gitignore. Mantén abierta la ventana del servidor mientras trabajas.
