Dimensiones y validación de cajas

Base USA, base UK y cajas propias de fincas. OP compara los pesos volumétricos.

Cada caja puede tener un U2 propio. Si queda vacío, se aplica el valor general de U2. Los cambios en la tabla permiten previsualizar el peso y el semáforo antes de guardar.
NombreTipoLargo cmAncho cmAlto cmU2 individual · cmPeso volumétricoAprobadoΔ vs. base

Peso volumétrico = (Largo + U2) × (Ancho + U2) × (Alto + U2) / 6000. Las cajas base usan U2 = 0. El U2 individual sobrescribe el valor general de Sheet1!U2; dejarlo vacío significa heredar el valor general.

Actualización automática

Cada vez que guardas un producto, una imagen, una caja o importas un Excel, Flowerpedia actualiza el catálogo de la raíz: index.html, catalog-public.json y las imágenes públicas. No tienes que preparar ni exportar el catálogo manualmente.

El panel y los datos de trabajo permanecen en tu ordenador. GitHub Desktop solo publica el catálogo y los archivos públicos cuando tú haces Commit + Push. No subas private/data/ ni los archivos BAT.
